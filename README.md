## 旧设备说明

继续保留串行背景预热、特效延迟加载、压缩 MP3、手动点击播放以及低像素比等旧设备优化。音乐播放和图片加载仍受旧浏览器、网络质量和设备内存影响。

## 安全说明

Cloudflare Pages 不需要旧的服务器部署脚本。本版本未包含旧 `deploy.py` 文件，因为它曾包含硬编码服务器凭据；如果该文件已上传到公开仓库，请将其从仓库删除并轮换相关密码。

## 新增：二战中国步枪（枪械分类）与钢盔军帽

武器选择页新增「枪械」分类，头盔选择页末尾新增 8 顶钢盔/军帽。全部为程序绘制（`js/gear.js`），不依赖新图片；枪声、拉栓声为 WebAudio 合成（`js/audio.js`）。

| 枪械 | 伤害 | 特征 |
|---|---|---|
| 老套筒 | 11 | 早期汉阳造，枪管外有隔热钢套筒 |
| 汉阳造 | 14 | 八八式，外露弹仓 |

- 玩家使用枪械时需主动按虚拟“射”键开火；自动瞄准保留。键盘操作为玩家1按 F，玩家2按小键盘 0 或 /。
- 没有小招 / 大招；开一枪后拉栓 2.5 秒才能再开火（枪上有拉栓动画，头顶和左下角有拉栓进度）。AI 保留原有自动开火行为。
- 想调数值：`js/weapons.js` 中的 `dmg`（伤害）、`bolt`（拉栓秒数）、`bulletSpeed`（子弹速度）。

## 2026-10-25 性能与地图修复

- 启动阶段仅预热默认地图，其他地图在选择时按需加载；特效图延后串行加载，减少慢网络首屏带宽竞争。
- 修复地图切换时战场画布未完整重绘导致的旧背景残留，并统一所有地图的 cover 铺满绘制。
- 竖屏设备的战斗画面适度放大，地图底图和两名玩家仍保持同一逻辑坐标系。
- 音乐播放器改为点击播放后再请求音频、逐文件名编码 URL，并在播放或资源加载失败时显示提示。
