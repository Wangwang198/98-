# 98班美国电竞房（旧设备优化版）

本版针对旧手机、低配置电脑和较慢网络做了优化：
- 11 首音乐统一压缩为 96 kbps MP3，保留原曲目名称和播放器功能，减少下载量。
- 音乐默认只预读元数据，不在网页启动时抢占带宽；点击播放后再缓冲，避免反复调用 play 导致卡顿。
- 游戏背景优先加载首张，其余背景串行预热；特效图片延后并串行加载，降低旧设备启动时的内存/网络峰值。
- 浮动贴纸图片压缩，减少首次加载体积。
- 低核心数设备降低 Canvas 像素比，减轻 GPU 和内存压力。

## GitHub Pages
保留所有原目录结构。上传时请把 `index.html`、`css/`、`js/`、`assets/` 放在仓库根目录；不要只上传 ZIP。

注意：浏览器可能限制自动播放。若网页打开后音乐没有自动播放，请点击播放器的“播放”按钮一次。低速网络播放仍取决于网络吞吐量。
