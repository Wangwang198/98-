# 98班美国电竞房

> 参考 [Poki - Stickman Battle](https://poki.com/zh/g/stickman-battle)（EasyCats）实现的网页版火柴人物理对战游戏。
> 纯 HTML + CSS + JavaScript（Canvas 2D）实现，无需重型引擎；电脑端支持鼠标点击虚拟按键，移动端支持触屏虚拟按键。

---

## 一、参考游戏分析（Poki · Stickman Battle）

通过实际打开并分析参考站点与游戏截图，提炼出核心设计：

| 维度 | 参考游戏做法 | 本项目的吸收与增强 |
| --- | --- | --- |
| 主菜单 | 大标题 + 「1 Player / 2 Players」两个大卡片按钮 | 保留，中文化：「单人对战 AI / 双人对战」，加入关卡选择与设置 |
| 备战大厅 | 左右两侧各一名玩家，可选 武器(Weapon) / 皮肤(Skin·头盔) / 颜色(Color)，中间宝箱 + FIGHT | 完整复刻并扩展：武器/头盔带**特殊技能效果**，所有武器与头盔默认解锁；宝箱免费并只奖励金币 |
| 战斗 | 布娃娃式物理火柴人、武器挥舞、血条、技能(Skill)+大招(Super)、倒计时炸弹机关 | 自研轻量物理（重力+惯性+击退+硬直），打击停顿(hit-stop)、屏幕震动、粒子火花、飘字伤害 |
| 操作 | P1: WASD + E技能 + Space大招（按住W大跳）；P2: 方向键 + Shift技能 + Enter大招 | 按需求调整：P1 大招改为 **R**（E小招/R大招），P2 右Shift小招 / Enter大招；移动端显示虚拟按键 |
| 经济 | 对局获得金币；全部武器与头盔直接解锁 | 赢一局 +50 金币；战斗中击中会**掉落金币**可拾取；免费宝箱只提供额外金币 |
| 表现 | 扁平卡通、纯色背景 + 远景剪影 | AI 生成**三国主题关卡背景**（赤壁/长坂坡/虎牢关等）+ 视差层次 + 动感三国风纯音乐 + 真实兵器音效 |

### 核心手感关键词（从参考游戏提炼）
1. **惯性物理**：角色不是刚性移动，带加速度/减速度，被击中有夸张击退与空中翻滚感。
2. **挥击弧线**：武器以肩/手腕为轴做弧线挥动，攻击判定在武器头部，带残影。
3. **打击反馈**：命中瞬间 hit-stop（约 60~90ms 停帧）+ 屏幕震动 + 火花粒子 + 伤害飘字 + 音效分层（挥空 whoosh / 命中 hit / 暴击 crit）。
4. **技能循环**：小招（短冷却，位移/远程/连击）与大招（能量条充满后释放，高伤害+AoE）。

### 原版源码反推（2026-08-06 实机抓取）
- 武器是真实物理刚体：命中瞬间先清零目标线/角速度，再按碰撞法线施加 `applyLinearImpulse`，配合 ragdoll 弹飞拉开距离。
- 每次挥击带 `damageInvert`（0.1s~1s）接触冷却，避免一次攻击反复判定；受击方有 `isInvincible / isShieldInvincible` 保护帧与护盾短暂无敌。
- 原版 AI：`actionInvertal = 2s`、技能间隔 `skillInvertal = 8s`、大招随机 8~12s；贴身时不会原地硬刚，会重新选角度与拉开距离。
- 武器配置含 `addHp`（部分武器增加生命上限）、多段子弹、反弹/范围/生成/充能等技能类型。
- 本作吸收：命中无敌帧反震弹开、身体推挤增强、AI 出招/受击后摇撤步、部分神兵生命上限被动。

## 二、功能设计

### 2.1 游戏模式
- **单人模式**：P1 vs AI（AI 三档难度：简单/普通/困难，影响反应速度、进攻欲望、格挡率）。
- **双人模式**：同屏本地对战，P1 vs P2。

### 2.2 操作方式
| 动作 | P1（PC） | P2（PC） | 移动端 |
| --- | --- | --- | --- |
| 左右移动 | A / D | ← / → | 虚拟左右键 |
| 跳跃（按住=大跳） | W（按住蓄力跳更高） | ↑（按住） | 虚拟跳跃键（按住） |
| 下蹲/快速下落 | S | ↓ | 虚拟下键 |
| 小招 (Skill) | **E** | **右 Shift** | 虚拟技能键 |
| 大招 (Super) | **R**（15秒充能） | **Enter**（15秒充能） | 虚拟大招键（能量满可用） |
| 暂停 | P / Esc | P / Esc | — |

> 电脑端和移动端都会显示虚拟按键层；电脑可直接用鼠标点击，也保留原有键盘操作。

### 2.3 角色与物理
- 火柴人由 头/躯干/双臂/双腿 程序化生绘（Canvas），关节用**反向运动学简化**：走路摆腿、跳跃收腿、受击后仰、挥击时身体跟随前倾。
- 物理参数：重力 `0.6`、地面摩擦 `0.82`、空气阻力 `0.98`、移动加速度、击退向量+受击硬直（hitstun）、落地尘土。
- 头部为弱点：爆头 ×1.5 伤害并触发暴击特效。

### 2.6 经济系统
- 胜利 **+50 金币**，失败 +10 金币；每次命中 20% 概率掉落金币（1~5），金币落地弹跳，走近自动拾取。
- **自由解锁模式：**全部武器与头盔直接开放，无需花费金币；免费宝箱提供额外金币奖励。
- 金币、全量解锁状态、最高连胜存 `localStorage`。

### 2.7 关卡（三国主题，AI 生成背景图 + 视差）
1. **长坂坡**（黄昏战场，断旗残垣）
2. **赤壁**（夜战，火光连船）
3. **虎牢关**（雄关城墙，战云密布）
4. **五丈原**（秋夜星空，营火）
> 战斗机制差异：赤壁随机落火雨、虎牢关有中央炸弹倒计时机关（致敬参考游戏截图中的炸弹）、五丈原重力略低（跳跃更飘）。

### 2.8 表现与氛围
- **背景图**：`gpt-image-2`（主）与 `Qwen-image`（补充）生成，加载失败回退为 Canvas 程序化渐变+剪影。
- **音乐**：`music-2.6` 生成动感三国打斗纯音乐（循环播放）；菜单与战斗不同曲目。
- **音效**：本地素材库（刀剑碰撞/挥动/武术/爆炸）挑选拷贝至 `assets/sfx/`；同时内置 WebAudio 合成兜底，保证任何环境可玩。
- **特效**：粒子系统（火花/尘土/金币/剑气）、hit-stop、屏幕震动、慢动作（大招命中）、伤害飘字、血条动画、能量条。

## 三、技术架构

```
play-fight-huocai/
├── index.html            # 单页入口（菜单/大厅/战斗/结算 全在一个页面内切换）
├── css/style.css         # 全部 UI 样式（绚丽渐变、发光、动画）
├── js/
│   ├── main.js           # 入口、场景状态机（menu→lobby→battle→result）
│   ├── game.js           # 战斗主循环、物理、碰撞、相机、震动
│   ├── player.js         # 火柴人角色：骨骼程序化动画、攻击、技能
│   ├── weapons.js        # 武器/头盔数据表（含技能定义）
│   ├── effects.js        # 粒子、飘字、剑气、金币
│   ├── audio.js          # 音乐/音效管理（本地素材 + WebAudio 兜底）
│   ├── ai.js             # AI 对手（状态机：接近/进攻/闪避/抢金币）
│   ├── ui.js             # 菜单、大厅、宝箱、虚拟按键、HUD
│   └── assets.js         # 资源清单与预加载（背景图/音乐/音效）
├── assets/
│   ├── bg/               # AI 生成的关卡背景（bg_changban.jpg 等）
│   ├── music/            # AI 生成的 BGM
│   ├── sfx/              # 拷贝自本地音效素材库
│   └── img/              # 宝箱、logo 等小图（Qwen-image/手绘SVG）
└── README.md
```

### 关键技术点
- **渲染**：单 `<canvas>`，逻辑分辨率 1280×720，按窗口等比缩放（letterbox）；`requestAnimationFrame` + 固定步长物理（60Hz 累积器），掉帧不瞬移。
- **性能**：对象池（粒子/飘字/金币复用）、离屏 canvas 缓存背景视差层、限制同屏粒子数（<400）、避免每帧字符串拼接与 DOM 操作（HUD 用 canvas 绘制）。
- **打击感公式**：命中 = hit-stop(60~90ms) + 震屏(强度∝伤害) + 击退(方向×伤害) + 火花(12~20粒子) + 飘字 + 音效。
- **移动端**：虚拟按键层（pointer events 多点触控）、viewport 锁定、按钮半透明按压反馈。
